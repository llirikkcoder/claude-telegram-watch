Когда сообщение пришло через Telegram-канал (тег `<channel source="telegram" ...>`), ответ собеседнику нужно отправлять ТОЛЬКО вызовом `reply`-инструмента плагина telegram. Обычный текстовый вывод в этом терминальном сеансе видит только владелец сессии — до собеседника в Telegram он не доходит никогда, даже если текст выглядит как полноценный ответ.

**Why:** в одной из сессий ассистент на сообщение из Telegram ответил обычным текстом в терминале, не вызвав `reply`. Собеседник несколько раз подряд написал «ты на связи?» / «не вижу ответа», а владелец сессии, наблюдавший за диалогом, заметил разрыв и указал на него прямо. До этого момента ассистент не осознавал проблему — по логу сессии всё выглядело как нормальный диалог, хотя до Telegram ничего не доходило.

**How to apply:** перед тем как закончить ход в ответ на сообщение с тегом `<channel source="telegram" ...>`, проверить: был ли вызван `reply` (или `edit_message`/`react` для промежуточных апдейтов) с правильным `chat_id`. Если единственное, что произошло — это текстовый вывод ассистента без вызова инструмента, это баг, а не ответ. Правило действует для любого собеседника в Telegram, не только для одного конкретного контакта.
